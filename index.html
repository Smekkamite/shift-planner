1. Defaults, individual rules & availability

Team defaults can be overridden below for a person or a single week. Weeks are planned independently. Consecutive rest may cross a week boundary; separated rest avoids adjacent days across boundaries too. No workday target removes the weekly day-count constraint.

The example has 7 fictional team members, 28 days and 5 shift positions per day. Change the rules and adjust staffing demand to match your team. Edit names, availability and shifts below. No code or JSON editing needed.

Checked = available to work. Uncheck to block a day. The planner respects each person’s rules for each week. Rule conflicts are shown and block approval; you can change the rule or use No workday target.
